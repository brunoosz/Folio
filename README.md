# Folio — Corpo, rotina e ciência

Caderno inteligente de saúde e treino. PWA mobile-first.

## Como rodar

```bash
npm install
npm run dev
```

Acesse `http://localhost:5173`.

## Stack

React + Vite + TypeScript + Tailwind v4 + Zustand + React Router + @dnd-kit

## Estrutura

```
src/
  brand/        — config de marca, logo
  components/   — UI base, ilustrações, splash
  pages/        — Home, Treino, Mapa
  data/         — mock data e repositórios
  hooks/        — hooks customizados
  lib/          — utilitários
db/
  schema.sql    — modelo de dados (não aplicado)
```
